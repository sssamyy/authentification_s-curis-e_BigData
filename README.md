# 🔐 Application d’Authentification Multi-Facteurs dans le Big Data

Projet universitaire présentant différentes méthodes d’authentification appliquées au **Big Data**, développé avec le framework **Flask (Python)**.

---

## 📘 Objectif
Fournir une **plateforme d’expérimentation** pour les principales techniques d’authentification utilisées dans les environnements Big Data :
- Sécurisation des accès distribués.
- Vérification multi-facteurs (MFA).
- Validation des identités utilisateurs via OTP/TOTP.

---

## ⚙️ Fonctionnalités
- **Authentification par e-mail** (envoi d’un lien ou code de vérification).  
- **Authentification par notification** (push/confirmation).  
- **Authentification biométrique** (ex. empreinte ou reconnaissance faciale simulée).  
- **OTP (One-Time Password)** basé sur une clé temporaire.  
- **TOTP (Time-based One-Time Password)** avec expiration dynamique.  
- **oAuth** (intégration optionnelle pour services tiers).
